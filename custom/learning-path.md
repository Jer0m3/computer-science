# Learning path

One linear order through the OSSU curriculum with the practice built in. Work through the stages from top to bottom: **learn** the courses first, then **practice** with the challenges listed right below them. Each challenge only uses what the stages before it have taught.

Tick the boxes as you go (`- [x]`). Details for each challenge: [practice.md](practice.md).

> **Running in parallel right now:** [SANS SEC555 / GCDA](sec555-gcda.md). In this path it belongs to stage 10, but you are already doing it, so it stays its own track.

---

## Stage 1 – Getting started

**Learn**
- [ ] Introduction to Computer Science and Programming using Python
- [ ] The Missing Semester of Your CS Education

**Practice**
- [ ] [Exercism](https://exercism.org) – Python track
- [ ] [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) – Linux shell basics
- [ ] [Advent of Code](https://adventofcode.com) – the first 10 days of any year

## Stage 2 – Programming

**Learn**
- [ ] Systematic Program Design
- [ ] Class-based Program Design
- [ ] Programming Languages
- [ ] Object-Oriented Design
- [ ] Software Architecture

**Practice**
- [ ] [Coding Challenges](https://codingchallenges.fyi) – start with wc, JSON parser, grep
- [ ] [CodeCrafters](https://app.codecrafters.io) or [Build your own X](https://github.com/codecrafters-io/build-your-own-x) – one bigger project (e.g. your own Git or Redis)

## Stage 3 – Math

**Learn**
- [ ] Calculus 1A, 1B, 1C
- [ ] Mathematics for Computer Science

**Practice**
- [ ] [Project Euler](https://projecteuler.net) – the first 25 problems
- [ ] [CryptoHack](https://cryptohack.org) – Introduction, General and Mathematics categories

## Stage 4 – Security basics

**Learn**
- [ ] Cybersecurity Fundamentals
- [ ] Principles of Secure Coding
- [ ] Identifying Security Vulnerabilities

**Practice**
- [ ] [picoCTF](https://picoctf.org) – practice gym, easy challenges
- [ ] [TryHackMe](https://tryhackme.com) – beginner paths
- [ ] [Cryptopals](https://cryptopals.com) – sets 1 to 4 (encoding, XOR, block cipher modes, CBC padding oracle)
- [ ] [OWASP WrongSecrets](https://github.com/OWASP/wrongsecrets)

## Stage 5 – How computers work

**Learn**
- [ ] Nand to Tetris Part I
- [ ] Nand to Tetris Part II

**Practice**
- [ ] [Microcorruption](https://microcorruption.com) – assembly and debugging on a simulated chip
- [ ] [crackmes.one](https://crackmes.one) – easy reverse engineering challenges

## Stage 6 – Operating systems and memory bugs

**Learn**
- [ ] Operating Systems: Three Easy Pieces
- [ ] Identifying Security Vulnerabilities in C/C++ Programming

**Practice**
- [ ] [Exploit Education Phoenix](https://exploit.education) – stack, format strings, heap
- [ ] [pwn.college](https://pwn.college) – the first modules
- [ ] [OverTheWire Leviathan and Narnia](https://overthewire.org/wargames/)

## Stage 7 – Networking

**Learn**
- [ ] Computer Networking: a Top-Down Approach (with the Wireshark labs)

**Practice**
- [ ] [Protohackers](https://protohackers.com) – write your own network servers
- [ ] [flAWS](http://flaws.cloud) – first look at cloud misconfigurations

## Stage 8 – Algorithms and the rest of Core CS

**Learn**
- [ ] Algorithms: Design and Analysis, Part 1 and Part 2
- [ ] Exploiting and Securing Vulnerabilities in Java Applications
- [ ] Core applications (Databases, Machine Learning, Computer Graphics, Software Engineering)
- [ ] Core ethics

**Practice**
- [ ] [Cryptopals](https://cryptopals.com) – sets 5 to 8 (Diffie-Hellman, RSA, hashes, elliptic curves; uses the number theory from stage 3)
- [ ] [Root Me](https://www.root-me.org) – mixed categories

## Stage 9 – Web security

**Learn**
- [ ] Web Security Fundamentals

**Practice**
- [ ] [PortSwigger Web Security Academy](https://portswigger.net/web-security) – all apprentice labs, then practitioner
- [ ] [OverTheWire Natas](https://overthewire.org/wargames/natas/)

## Stage 10 – Forensics and detection

**Learn**
- [ ] Digital Forensics Concepts
- [ ] [SANS SEC555 / GCDA](sec555-gcda.md)

**Practice**
- [ ] [Splunk Boss of the SOC v3](https://github.com/splunk/botsv3)
- [ ] [CyberDefenders](https://cyberdefenders.org)
- [ ] [Blue Team Labs Online](https://blueteamlabs.online)
- [ ] [flAWS 2](http://flaws2.cloud) – defender path
- [ ] [CloudGoat](https://github.com/RhinoSecurityLabs/cloudgoat)

## Stage 11 – Advanced CS

**Learn**
- [ ] Advanced programming (Parallel Programming, Compilers, …)
- [ ] Advanced systems (Computation Structures 1 to 3)
- [ ] Advanced theory, Advanced math
- [ ] Remaining Advanced Information Security courses

**Practice**
- [ ] [Gossip Glomers](https://fly.io/dist-sys/) – distributed systems, after Parallel Programming
- [ ] [ROP Emporium](https://ropemporium.com) and [pwnable.kr](https://pwnable.kr) – after Computation Structures
- [ ] [Flare-On](https://flare-on.com) – past years
- [ ] [Hack The Box](https://www.hackthebox.com)

## Any time after stage 4

- [SANS Holiday Hack Challenge](https://www.sans.org/mlp/holiday-hack-challenge/) – every December
- [CTFtime](https://ctftime.org) – join a live CTF event
