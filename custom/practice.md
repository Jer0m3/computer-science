# Hands-on practice

Practical challenges to go alongside the courses. Most of them work like [Cryptopals](https://cryptopals.com): a fixed set of exercises that build on each other, where you write the code or the exploit yourself.

**Order:** the Stage column refers to the [learning path](learning-path.md). Do each challenge after finishing the courses of that stage.

Status legend: ✅ done · 🟡 in progress · ⬜ planned

## Cryptography

Challenge | Status | What you do | Stage
:-- | :--: | :-- | :--
[Cryptopals](https://cryptopals.com) | ⬜ | 8 sets: implement real-world crypto attacks yourself (CBC padding oracle, ECB, MT19937, RSA…) | 4 (sets 1–4), 8 (sets 5–8)
[CryptoHack](https://cryptohack.org) | ⬜ | Guided crypto challenges, from encoding basics to RSA, ECC and lattices | 3
