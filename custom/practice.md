# Hands-on practice

Practical challenges to go alongside the courses. Most of them work like [Cryptopals](https://cryptopals.com): a fixed set of exercises that build on each other, where you write the code or the exploit yourself.

Status legend: ✅ done · 🟡 in progress · ⬜ planned

## Cryptography

Challenge | Status | What you do | Fits after
:-- | :--: | :-- | :--
[Cryptopals](https://cryptopals.com) | ⬜ | 8 sets: implement real-world crypto attacks yourself (CBC padding oracle, ECB, MT19937, RSA…) | Core programming, Core security
[CryptoHack](https://cryptohack.org) | ⬜ | Guided crypto challenges, from encoding basics to RSA, ECC and lattices | Core math
